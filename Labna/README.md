# لبنة — Labna

تطبيق iOS Native تجريبي لعرض منتجات الألبان وبناء تجربة تسوق كاملة بالعربية والإنجليزية. يتيح التطبيق تصفح الكتالوج، اختيار العبوات، حفظ السلة محليًا، ومراجعة طلب تجريبي دون دفع أو إرسال طلب شراء فعلي.

> **تنبيه:** المنتجات والأسعار والفروع والطلب داخل النسخة الحالية بيانات تجريبية. لا يجمع التطبيق عنوانًا أو رقم هاتف أو بيانات دفع، ولا يرسل طلبًا إلى متجر أو خادم.

## المزايا

- واجهة SwiftUI تدعم iOS 17 وما بعده.
- العربية والإنجليزية مع تبديل فوري بين RTL وLTR وحفظ اللغة المختارة.
- تصميم Light-only بألوان لبنة: الأبيض، الكريمي، الأخضر الداكن، والأخضر الفاتح.
- كتالوج محلي من ملفات JSON مع طبقة Repository قابلة للاستبدال بـ Remote API.
- منتجات متعددة العبوات، بحد أقصى ثلاث عبوات لكل منتج.
- أسعار صحيحة بوحدات العملة الصغرى، دون استخدام `Double` في الحسابات.
- تحميل الصور وتخزينها المؤقتًا باستخدام NukeUI.
- سلة محفوظة على الجهاز باستخدام SwiftData.
- مراجعة طلب تجريبي وإنشاء ملخص محلي برقم مرجعي `DEMO-...`.
- فروع تجريبية، خرائط MapKit، وفتح الاتجاهات في Apple Maps.
- دعم Dynamic Type وVoiceOver وReduce Motion وحالات التحميل والخطأ والفراغ.

## التقنيات

| المجال | التقنية |

| الواجهة | SwiftUI |

## المعمارية

التطبيق منظم حسب الميزات، مع فصل الشاشات عن مصدر البيانات:

```text
SwiftUI Views
      ↓
Stores / Feature Logic
      ↓
CatalogRepository
      ↓
JSONCatalogRepository
      ├── LocalJSONDataSource
      └── RemoteCatalogDataSource
```

`AppContainer` هو Composition Root للتطبيق، وينشئ ويشارك:

- `AppSettings`: اللغة وإعداداتها المحفوظة.
- `AppConfiguration`: اختيار مصدر البيانات المحلي أو البعيد.
- `CatalogRepository` و`CatalogStore`: تحميل الكتالوج وإدارة حالات التحميل.
- `CartStore`: منطق السلة والمزامنة مع SwiftData.
- `ModelContainer`: مخزن SwiftData.
- `AppRouter`: اختيار التبويب ومسار تنقل السلة.

تستهلك الشاشات `CatalogRepository` عبر `CatalogStore`، ولذلك يمكن الانتقال من JSON المحلي إلى API دون تغيير واجهات العرض.

## التنقل الرئيسي

يعتمد التطبيق على أربعة تبويبات، ولكل تبويب `NavigationStack` مستقل:

1. **الرئيسية:** البانرات والأقسام والمنتجات المميزة والبحث السريع.
2. **المنتجات:** الكتالوج الكامل والبحث والتصفية والترتيب.
3. **السلة:** إدارة المنتجات المحفوظة والانتقال إلى مراجعة الطلب.
4. **المزيد:** اللغة، معلومات التطبيق، الفروع، والتواصل.

يعرض تبويب السلة Badge بعدد الوحدات. يدير `AppRouter` الانتقال من شاشة نجاح الطلب إلى الرئيسية أو المنتجات، مع إعادة ضبط مسار Checkout.

## شرح الشاشات

### شاشة البداية

- تستخدم ألوان وشعار لبنة أثناء تشغيل التطبيق.
- تُعرّف من خلال `Info.plist` وأصول `LaunchBackground` و`LaunchLogo`.
- لا تحتوي على منطق أو انتظار مصطنع؛ ينتقل النظام إلى التطبيق فور اكتمال التشغيل.

### الرئيسية

- تعرض شعار لبنة داخل App Bar هادئ.
- يحتوي الشريط على زر بحث يتمدد إلى حقل بحث مع تركيز تلقائي، ويمكن إغلاقه لمسح النص.
- تعرض جميع بانرات `banners.json` داخل Carousel بعرض الشاشة الكامل.
- يتحرك الـ Carousel تلقائيًا كل خمس ثوانٍ، ويدعم السحب ومؤشرات الصفحات.
- يتوقف التحريك في الخلفية، ولا يعمل تلقائيًا عند تفعيل Reduce Motion.
- يفتح كل بانر المنتج أو القسم المشار إليه في بياناته.
- تعرض الأقسام أفقيًا ثم المنتجات المميزة في شبكة من عمودين.
- يبحث النص فورًا في اسم المنتج ووصفه ومكوناته باللغة الحالية.
- تعرض حالة فارغة وزر مسح البحث عند عدم وجود نتائج.
- يفتح زر الإضافة السريعة نافذة اختيار العبوة والكمية.

### المنتجات والكتالوج

- تعرض جميع المنتجات أو تفتح بقسم محدد عند الوصول إليها من الرئيسية.
- تدعم البحث باللغة المعروضة والتصفية حسب القسم.
- خيارات الترتيب: المميزة، الاسم، السعر تصاعديًا، والسعر تنازليًا.
- يعتمد ترتيب السعر على أقل سعر لعبوة متاحة، وتظهر المنتجات النافدة في النهاية.
- تعرض عدد النتائج وإجراءً لمسح البحث والفلاتر.
- تستخدم بطاقات المنتج نفسها الموجودة في الرئيسية، مع فتح التفاصيل أو الإضافة السريعة.

### نافذة الإضافة السريعة

- تظهر كـ Bottom Sheet من بطاقة المنتج.
- تعرض العبوات المتاحة وغير المتاحة بوضوح.
- تسمح بتحديد العبوة والكمية وتعرض الإجمالي قبل الإضافة.
- تدمج الإضافة مع السطر الموجود إذا تطابق المنتج والعبوة.
- تعرض رسالة نجاح قصيرة بعد الإضافة.

### تفاصيل المنتج

- تعرض معرض صور مع مؤشرات صفحات عند وجود أكثر من صورة.
- تعرض الاسم والوصف، ثم عبوات المنتج من واحدة إلى ثلاث عبوات.
- تكون العبوة غير المتاحة ظاهرة ولكن غير قابلة للاختيار.
- تسمح بتغيير الكمية ضمن الحدود الآمنة.
- تعرض المكونات وتعليمات الحفظ داخل أقسام قابلة للفتح.
- يحتوي أسفل الشاشة على زر ثابت يعرض إجمالي سعر العبوة والكمية.
- يُعطل زر الإضافة إذا لم توجد عبوة متاحة.

### السلة

- تعرض حالة فارغة عندما لا توجد منتجات.
- يعرض كل سطر صورة المنتج، الاسم، العبوة، سعر الوحدة، الكمية، الإجمالي الفرعي، والحذف.
- تدمج العبوات المتطابقة وتعرض العبوات المختلفة كسطور مستقلة.
- تسمح بتعديل الكمية من 1 إلى 99 وتحفظ كل تغيير مباشرة في SwiftData.
- تراجع العناصر المستعادة مقابل الكتالوج الحالي.
- تبقي المنتج أو العبوة المحذوفة أو غير المتاحة ظاهرًا وقابلًا للحذف، لكنها تستبعده من الإجمالي وتعطل تعديل كميته.
- تعرض السعر القديم مشطوبًا والسعر الحالي إذا تغيّر السعر بعد الإضافة.
- تعرض عدد الوحدات والإجمالي الحالي وتحذيرات التوفر أو فشل الحفظ.
- لا تسمح بمتابعة الطلب إذا كانت السلة فارغة أو تحتوي عناصر غير متاحة.

### مراجعة الطلب التجريبي

- تعرض تنبيهًا واضحًا بأن العملية تجريبية ولا تتضمن دفعًا أو إرسال طلب فعلي.
- تعرض المنتجات والعبوات والكميات والإجماليات الحالية.
- توفر حقل ملاحظات اختياريًا فقط؛ لا تطلب عنوانًا أو هاتفًا أو معلومات دفع.
- تتحقق مجددًا من السلة والتوفر وتناسق العملة قبل التأكيد.
- تمنع الضغط المتكرر أثناء المعالجة.
- تنشئ `DemoOrder` محليًا مع snapshots ثنائية اللغة للأسعار والأسماء والعبوات والكميات.
- تفرغ السلة المحفوظة فقط بعد نجاح إنشاء الطلب التجريبي.

### نجاح الطلب

- تعرض علامة النجاح ورقمًا مرجعيًا قابلًا للتحديد بصيغة `DEMO-...`.
- تعرض نسخة ثابتة من سطور الطلب والإجمالي والملاحظات إن وجدت.
- تؤكد أن الطلب لم يُرسل ولم يُحصّل أي مبلغ.
- توفر زرًا للعودة إلى الرئيسية وزرًا لفتح المنتجات.
- لا تحفظ الطلب أو ترسله إلى خادم؛ يبقى ملخصه لشاشة النجاح الحالية فقط.

### المزيد

- تعرض نبذة مختصرة عن لبنة.
- توفر اختيار العربية أو الإنجليزية عبر Segmented Picker.
- يطبق تغيير اللغة والاتجاه فورًا ويحفظ الاختيار في `UserDefaults`.
- تحتوي على روابط صفحات عن لبنة، الفروع، وتواصل معنا.
- تعرض توضيح النسخة التجريبية ورقم الإصدار والبناء من Bundle ديناميكيًا.

### عن لبنة

- تشرح فكرة التطبيق وتجربة كتالوج منتجات الألبان.
- توضح دعم اللغتين ونطاق النسخة التجريبية.

### تواصل معنا

- توضح أن بيانات التواصل الرسمية غير متاحة في النسخة الحالية.
- لا تعرض بريدًا أو رقم هاتف وهميًا، ويمكن إضافة الإجراءات عند توفير بيانات حقيقية.

### قائمة الفروع

- تقرأ الفروع من `CatalogStore` عبر مصدر البيانات نفسه المستخدم للكتالوج.
- تدعم حالات التحميل والفشل وإعادة المحاولة والفراغ.
- تعرض اسم الفرع وعنوانه ومواعيده، مع وسم واضح للفروع التجريبية.
- تفتح شاشة التفاصيل عند اختيار فرع.

### تفاصيل الفرع

- تعرض الاسم والعنوان المحليين حسب اللغة.
- تعرض خريطة MapKit مع علامة على إحداثيات الفرع وإمكانية التحريك والتقريب.
- تفتح اتجاهات القيادة في Apple Maps.
- تعرض مواعيد الأيام السبعة بتنسيق وقت يتبع اللغة الحالية.
- تعرض تنبيهًا عندما يكون الموقع تجريبيًا.
- لا يظهر زر الاتصال إلا لفرع حقيقي غير تجريبي يملك رقم هاتف صالحًا.

## البيانات المحلية

توجد البيانات داخل `Labna/Resources/Data/`:

| الملف | المحتوى |
|---|---|
| `categories.json` | أقسام المنتجات وترتيبها وصورها |
| `products.json` | المنتجات والترجمات والصور والعبوات والأسعار والتوفر |
| `banners.json` | بانرات الرئيسية ووجهة كل بانر |
| `branches.json` | الفروع والإحداثيات ومواعيد العمل |

قواعد مهمة عند تعديل البيانات:

- يجب أن تكون المعرّفات ثابتة وفريدة، بما فيها معرف كل بانر وعبوة.
- النص المحلي يأخذ الشكل `{ "ar": "...", "en": "..." }`.
- يحتوي المنتج على عبوة واحدة إلى ثلاث عبوات.
- `priceMinor` عدد صحيح بالقروش؛ `4500` يساوي 45 جنيهًا مصريًا.
- يجب أن تشير علاقات المنتج والقسم ووجهات البانرات إلى معرّفات موجودة.
- يجب أن تكون روابط الصور HTTPS.
- شغّل `MockDataTests` بعد كل تعديل.

الصور الحالية روابط Unsplash عامة لأغراض العرض الداخلي فقط، وليست أصول نشر نهائية أو تمثيلًا دقيقًا لكل عبوة. راجع `../Docs/MockData.md` قبل النشر العام.

## الانتقال إلى Remote API

المصدر الافتراضي هو `.localJSON`. لاستخدام API، أنشئ الحاوية بإعداد بعيد:

```swift
AppContainer(
    configuration: AppConfiguration(
        dataSource: .remote(
            baseURL: URL(string: "https://example.com/v1/catalog/")!
        )
    )
)
```

العقد الحالي يتوقع طلبات `GET` للمسارات التالية:

```text
products
categories
banners
branches
```

يجب أن تكون الاستجابات Arrays متوافقة مع نماذج التطبيق الحالية. إذا اختلف عقد API، يمكن إضافة DTOs وMapper أو Repository جديد وحقنه في `AppContainer` دون تعديل الشاشات. لا يوجد fallback تلقائي إلى JSON المحلي عند فشل المصدر البعيد.

## التخزين المحلي

- تحفظ اللغة المختارة في `UserDefaults`.
- تحفظ السلة في SwiftData باستخدام `PersistedCartItem`.
- يجمع مفتاح عنصر السلة بين معرف المنتج ومعرف العبوة.
- تحفظ السلة snapshots عربية وإنجليزية للاسم والعبوة وسعر الإضافة، حتى يظل العنصر قابلًا للعرض إذا تغيّر الكتالوج.
- تستخدم المعاينات والاختبارات `ModelContainer` داخل الذاكرة لتجنب تعديل بيانات المستخدم.
- لا يتم حفظ `DemoOrder` بعد مغادرة شاشة النجاح.

## نظام التصميم وإتاحة الاستخدام

- يثبت `AppRootView` الوضع الفاتح لتجنب تعارض الألوان الحالية مع Dark Mode.
- توجد ألوان ومسافات وحواف وخطوط دلالية في `Core/DesignSystem`.
- تعتمد الخطوط على أنماط النظام وتدعم Dynamic Type.
- تستخدم الواجهة `leading` و`trailing` للحفاظ على RTL وLTR.
- توفر المكونات مناطق لمس مناسبة وتسميات VoiceOver ومعرفات ثابتة لاختبارات UI.
- تستخدم `ProductImage` مساحة ثابتة أثناء التحميل وصورة بديلة وإعادة محاولة عند الفشل.
- تتكيف اختيارات العبوات مع المساحة وحجم النص باستخدام `ViewThatFits`.
- يمكن مراجعة المكونات بالعربية والإنجليزية وأحجام النص الكبيرة من `DesignSystemGallery.swift`.

## التشغيل

المتطلبات:

- macOS مع Xcode يدعم iOS 17 أو أحدث.
- اتصال بالإنترنت أول مرة لحل حزمة NukeUI، ولاحقًا لتحميل صور المنتجات.

الخطوات:

1. افتح `Labna.xcodeproj` في Xcode.
2. اختر Scheme باسم `Labna`.
3. اختر iPhone Simulator بنظام iOS 17 أو أحدث.
4. شغّل التطبيق باستخدام `Run`.

لا يحتاج التشغيل المحلي إلى مفاتيح API أو حساب مطور Apple. يحتاج التشغيل على جهاز فعلي أو الرفع إلى TestFlight إلى إعداد Team وBundle Identifier والتوقيع.

## الاختبارات

تشمل التغطية الآلية:

- فك JSON والعلاقات وفريدة المعرّفات والأسعار وحد العبوات.
- البحث والتصفية والترتيب بالعربية والإنجليزية.
- المصدر المحلي والبعيد وأخطاء HTTP وJSON والانقطاع والمهلة والإلغاء.
- استعادة السلة والدمج والكميات والحذف وتغير السعر وعدم التوفر.
- نجاح الطلب التجريبي ورفض السلة غير الصالحة ومنع التأكيد المتكرر.
- رحلات التصفح، اللغة، الحفظ، Checkout، الفروع، الخرائط، فشل الصور، والنص الكبير.

لتشغيل الاختبارات من داخل مجلد `Labna`:

```bash
xcodebuild -project Labna.xcodeproj \
  -scheme Labna \
  -destination 'platform=iOS Simulator,name=iPhone 17,OS=26.1' \
  test
```

غيّر اسم المحاكي وإصدار النظام حسب Runtimes المثبتة محليًا. يمكن أيضًا تشغيل `LabnaTests` و`LabnaUITests` من Test Navigator في Xcode.

## جاهزية الإصدار

- يحتوي المشروع على أيقونة أصلية 1024×1024 دون شفافية وشاشة بداية خاصة بلبنة.
- يدعم إنشاء Release build وArchive، لكن رفع TestFlight غير مهيأ دون حساب Apple Developer وسجل App Store Connect وتوقيع الفريق.
- يجب استبدال صور Unsplash أو توثيق حقوق استخدامها قبل النشر العام.
- يجب إجراء اختبار نهائي على جهاز فعلي لـ VoiceOver وشاشة البداية وتحميل الشبكة وتسليم الاتجاهات إلى Apple Maps.
- يجب مراجعة البيانات التجريبية والتأكد من فريدة جميع المعرّفات قبل إصدار أي نسخة خارجية.

لخطوات التسليم الكاملة راجع `../Docs/ReleaseReadiness.md`.
