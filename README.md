# Labna — لبنة

تطبيق iOS تجريبي لعرض منتجات الألبان وبناء تجربة تسوق كاملة بالعربية والإنجليزية: تصفح الكتالوج، اختيار العبوات، سلة محفوظة على الجهاز، ومراجعة طلب تجريبي بدون دفع أو إرسال طلب شراء فعلي.

## نظرة سريعة

- SwiftUI مع iOS 17 فأحدث، وواجهة Light-only.
- دعم العربية والإنجليزية مع تبديل فوري بين RTL وLTR.
- بيانات محلية من ملفات JSON عبر طبقة Repository قابلة للاستبدال بـ Remote API.
- سلة محفوظة بـ SwiftData، وطلب تجريبي برقم مرجعي محلي.

> البيانات الحالية تجريبية: المنتجات والأسعار والفروع توضيحية، والتطبيق لا يجمع عنوانًا أو هاتفًا أو بيانات دفع.
